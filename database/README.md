# ElectrospinTEK ERP - Relational Database Tier

This directory holds the relational SQLite database file (`db.sqlite3`) and database migration assets.

- **Active Database File**: `database/db.sqlite3`
- **Django ORM Models**: Managed by Python Django backend located in `../backend/api/models.py`
- **Django Admin Portal**: Accessible at `http://localhost:8000/admin/`
